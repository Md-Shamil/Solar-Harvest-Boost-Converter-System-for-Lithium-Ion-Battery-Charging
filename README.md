# 🌞 Solar Harvest: Boost Converter System for Lithium-Ion Battery Charging

This project demonstrates the design and implementation of a **solar-powered boost converter** optimized for charging lithium-ion batteries. It includes hardware, LTSpice simulation, and real-time testing to evaluate performance and efficiency.

---

## 📚 Project Overview

- 📍 **Objective**: Efficiently extract energy from a 4V solar panel and deliver it to a lithium-ion battery using a boost converter.
- ⚡ **Key Features**:
  - Boost converter with MPPT (Maximum Power Point Tracking)
  - Hardware prototyping
  - LTSpice simulation and validation
  - Real-world testing under sunlight conditions

---

## 🛠 Components Used

- 4V Solar Panel
- Boost Converter Circuit
- Lithium-Ion Battery
- Charge Controller
- MPPT Algorithm (if implemented)
- LTSpice for circuit simulation

- Safe and efficient charging achieved under controlled test conditions.
